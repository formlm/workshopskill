# The Advantage Compass — Start Here

> One page, thirty seconds, then print and go.

**What this is:** a personal strategy self-assessment — two axes, four quadrants, a two-week time audit, one committed move. Personality tests label you; this one locates you. 25 minutes, paper or online.

## Print list, by scenario

- **Teaching (25 min + Q&A):** the deck on screen (`advantage-compass-slide-deck.html`) or printed, one answer sheet per participant.
