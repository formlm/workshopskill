# Skill Radar — start here

One page, thirty seconds, then print and run.

**What this is:** a 20-minute, 6–16 person self-assessment tool. Each person plots their own capability across five or six axes as a radar chart, overlays the shape the role actually needs, and picks the one short spoke to invest in. 6–16 people · 20 minutes · offline + online.

## Pick a route

- **Just run it (5 min):** name the axes, rate yourself 1–5 and plot, overlay the target shape, mark the one short spoke, name one action.
- **Pair or manager overlay:** a trusted peer plots the same radar too — the mismatch is the feedback conversation.
- **Onboarding:** run it on day one against the role's target shape — it becomes the first 90-day plan.

## Set the room

Each person with a blank five- or six-spoke radar and two pens, working against the role's target shape — not against each other. Optional: put `skill-radar-activity-poster.pdf` on the wall so "read the shape, not the average" and "rate against the target" stay visible. Nothing needs a projector, and nothing needs an account to download.

## Print checklist

- Axes & step cards: poker spec, one set per person.
- Poster: A3, one per room (optional, but it holds the two rules up).
- Run sheet: A4 (or Letter), one per facilitator.
