# Four-Lens Sweep — Start Here

> One page, thirty seconds, then print and run.

**What this is:** A 20-minute, 4–10 person way to review one idea four times — through Facts, then Feelings, then Risks, then Upside — with everyone in the same lens at the same time, so the room looks at one object four ways instead of arguing positions. Printable lens cards, no account. 4–10 people · 20 min · offline + online.

## Pick your lane

- **Just run it (5 min):** put the idea up, run four single-lens passes timeboxed, then read the four columns and decide. No projector, no account.
- **Open a decision meeting with it:** run one sweep on the actual proposal so the group sees it whole before voting.
- **Remote:** the same four passes on a shared board; it transfers cleanly.
