# The Feedback Digest — start here

One page, thirty seconds, then print and run.

**What this is:** a 20-minute, 1–2 person self-assessment tool. Collect the feedback you've actually received, sort it into Already knew / Surprised me / I'll dismiss, read the surprised pile as your blindspot, then write one honest sentence the evidence supports and one action that follows from the surprise. No account, no projector. 1–2 people · 20 minutes · offline + online.

## Pick a route

- **Just run it (5 min):** write each feedback item on a card, sort into three piles, read the surprised pile for its pattern, write one sentence + one action.
- **After a review cycle:** digest one round while it's fresh; the surprised pile is your development plan.
- **With a trusted colleague:** they read your surprised pile back to you.

## Set the room

Solo at a desk, or a pair each working their own feedback. Three zones for the piles, cards for the items. Optional: put `the-feedback-digest-activity-poster.pdf` on the wall so "surprise is the signal" and "dismiss only with a reason" stay visible. Nothing needs a projector, and nothing needs an account to download.

## Print checklist

- Sorting + prompt cards: poker spec, one deck per person.
- Poster: A3, one per room (optional, but it holds the two rules up).
- Run sheet: A4 (or Letter), one per facilitator.
