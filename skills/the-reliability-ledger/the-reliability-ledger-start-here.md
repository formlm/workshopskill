# The Reliability Ledger — start here

One page, thirty seconds, then print and run.

**What this is:** a 25-minute, 4–10 person trust tool. A team writes what each person will reliably do and what each quietly needs, surfaces the one broken-but-unspoken expectation everyone had, and commits to one repair with an owner and a check-in date. Trust as a record of kept promises, not a feeling. No account, no projector. 4–10 people · 25 minutes · offline + online.

## Pick a route

- **Just run it (5 min):** two columns on a wall (Commitments · Needs), everyone writes 2 commitments + 1 need, read aloud and post, name the unspoken one, agree one repair + owner + check-in date.
- **After a specific rupture:** go straight to the unspoken one, then work backwards to the commitments that would have prevented it.
- **New team, week one:** write only commitments and needs; skip the unspoken one until there's history.

## Set the room

Two columns on the wall — Commitments and Needs — plus a spot for the unspoken one. Cards in hand, marker for the repair. Stick `the-reliability-ledger-activity-poster.pdf` up so "needs are requests, not grievances" and "no repair action = a complaint box" stay visible. Nothing needs a screen, nothing needs an account.

## Print list

- Cards: poker spec, one sheet per person (cut on the guides).
- Poster: A3, one per room (optional but recommended).
- Run sheet: A4 (or Letter), one for the facilitator.
