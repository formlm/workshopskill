# The Not-Anymore List — start here

One page, thirty seconds, then print and run.

**What this is:** a 25-minute, 4–12 person review pointed at subtraction. The team lists its recurring work, asks "if we weren't already doing this, would we start it today?", and actually stops one thing — with a "bring it back if…" trigger, an owner, and a review date so stopping is safe. No account, no projector. 4–12 people · 25 minutes · offline + online.

## Pick a route

- **Just run it (5 min):** list every recurring thing, run the "would we start it today?" test, pick one to stop, set a bring-back trigger + owner + review date, name what you'll do with the freed time.
- **Zombie-meeting audit:** run it only on recurring meetings; cancel the ones that fail for a month and see who notices.
- **Post-launch:** point it at the process that got you across the line — most of it shouldn't survive.

## Set the room

Two columns on the wall — On the list · What we'll stop. Cards in hand. Stick `the-not-anymore-list-activity-poster.pdf` up so "subtraction only" and "every stop needs a bring-back trigger" stay visible. Nothing needs a screen, nothing needs an account.

## Print list

- Cards: poker spec, one sheet per group (cut on the guides).
- Poster: A3, one per room (optional but recommended).
- Run sheet: A4 (or Letter), one for the facilitator.
