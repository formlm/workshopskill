# Yes-And Ramp — Start Here

> One page, thirty seconds, then print and run.

**What this is:** A 15-minute, 4–12 person creativity drill where a group builds one idea by each person saying "yes, and…" and adding a turn — accepts only, never "but" — so a plain seed climbs until it's unrecognisable. It trains building-on-others over editing-them. Printable prompt cards, no account. 4–12 people · 15 min · offline + online.

## Pick your lane

- **Just run it (5 min):** put an ordinary seed on a card or the board, go around three times with "yes, and," read the whole ramp back. No projector, no account.
- **Open a real session with it:** run one ramp on the actual topic you're about to design — it warms the group into building instead of judging.
- **Remote:** the same round by name on a call; it transfers cleanly.

## Print list (per group)

One seed card per ramp, one rule card for the room, and a sheet to log the running ramp so the read-back is visible. The `yes-and-ramp-activity-poster.pdf` goes on the wall so the "yes, and — no but" rule stays up. Nothing needs a projector.
