# The Listening Ladder — Start Here

> One page, thirty seconds, then print and run.

**What this is:** Three rounds of listening that climb from the words, to the feeling under them, to what was left unsaid — a third person holds a two-faced validator card and says only *landed* or *not yet*. Pairs or trios · 15 min · offline · with a pre/post measure that scores the pair, never a person.

## Pick your lane

- **Just run it (5 min):** print one prop-card set per trio, read the run-sheet timings, run rounds A → B → C, debrief from the questions. No account, no projector.
- **Measure it:** run the pre-measure before pairing and the post-measure after the debrief — score at pair level with `the-listening-ladder-assessment.json` (5 items, one reverse-scored). Offline scoring needs no tool; `SKILL.md` carries a copy-paste method.
- **Go online (optional):** lift the same 5 items into a live pre/post form — see the folder's *make it live* block. The paper version is complete without it.
