# Same Boat — Start Here

> One page, thirty seconds, then print and run.

**What this is:** A 20-minute, 6–16 person reframe for two sides stuck in a dispute: each side writes only what they will **both** lose if it keeps running, and the overlap becomes one shared "same boat" card — moving from "against them" to "beside them, facing the same problem." Printable cards, no account. 6–16 people · 20 min · offline + online.

## Pick your lane

- **Just run it (5 min):** seat the two sides apart, state the "both lose only" rule, write, compare, put overlaps on one card, reframe. No account, no projector.
- **Two rooms:** run the writing in separate breakouts, then reconvene to compare and build the card.
- **Make the costs real:** seed the first list with one concrete shared loss (a date, a sum, a launch) if the room freezes at "they're wrong."

## Print list (per pair of sides)

One per-side write card for each side, one large "same boat" card between them, one "still different" card to hold real disagreements. The `same-boat-activity-poster.pdf` goes on the wall so the "both lose only" rule stays visible. Nothing needs a projector or an account.
