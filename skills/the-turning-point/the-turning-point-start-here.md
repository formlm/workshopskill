# The Turning Point — start here

One page, thirty seconds, then print and run.

**What this is:** a 25-minute, 4–12 person review that rebuilds a project's timeline (start to now), marks the moments it turned up or down, names the decision or habit behind each turn, and commits to keep one good-turn habit and kill one bad-turn habit. No account, no projector. 4–12 people · 25 minutes · offline + online.

## Pick a route

- **Just run it (5 min):** draw the timeline, add real moments, circle the turning points, name each cause, then commit one habit to keep and one to kill — each with an owner and a date.
- **Mid-project check-in:** run it on the timeline so far; the pattern of turns tells you if you're accelerating or drifting.
- **Before a restart:** mark only the down-turns and their causes — your list of what not to repeat.

## Set the room

People who were on the same project, around one long timeline on the wall. Cards and sticky notes in hand. Optional: put `the-turning-point-activity-poster.pdf` on the wall so "real moments, not vibes" and "every turn has a cause" stay visible. Nothing needs a projector, and nothing needs an account to download.

## Print checklist

- Prompt cards: poker spec, one set per group.
- Poster: A3, one per room (optional, but it holds the two rules up).
- Run sheet: A4 (or Letter), one per facilitator.
