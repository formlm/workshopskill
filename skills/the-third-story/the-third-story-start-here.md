# The Third Story — Start Here

> One page, thirty seconds, then print and run.

**What this is:** A 25-minute, 4–10 person conflict reframe for two sides at odds: each tells, in the third person, the story a neutral observer would tell about what is happening between them — what a camera would see, not who's right — then both name the need under each position and commit one move that serves a need they share. Printable cards, no account. 4–10 people · 25 min · offline + online.

## Pick your lane

- **Just run it (5 min):** set the two rules, each side writes and reads its third story, post both, mark the shared scene and the divergence, name one need each, commit one shared-need move + owner + date. No account, no projector.
- **Two people, one mediator:** each tells the *other's* third story aloud; the mediator only stops the ones that slip into blame.
- **Before it hardens:** run it the first time you feel a split forming — a third story is cheapest before the sides have names.

## Print list (per pair of sides)

One set of prompt cards per side, and the two columns ("Our third story · Their third story") up on a shared board with a strip below for the needs. The `the-third-story-activity-poster.pdf` goes on the wall so the "third person only / what a camera would see" rules stay visible. Nothing needs a projector or an account.
