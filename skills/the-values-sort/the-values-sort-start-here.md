# The Values Sort — start here

One page, thirty seconds, then print and run.

**What this is:** a 20-minute, 1–8 person self-assessment tool. You sort a deck of value cards into Core / Important / Not mine — Core capped at five — then check one real recent decision against your five and close one gap. You find out what you actually value only when choosing costs you something. No account, no projector. 1–8 people · 20 minutes · offline + online.

## Pick a route

- **Just run it (5 min):** deal the cards, sort into three piles (five max in Core), cut to five, lay one recent decision next to them, name one change and date it.
- **Career crossroads:** run the test against the actual choice in front of you, not a past one.
- **Team alignment:** everyone sorts alone, then compare Core fives; the disagreements are where the friction lives.

## Set the room

Three piles on the table — Core (five slots), Important, Not mine. Deal the value cards. Stick `the-values-sort-activity-poster.pdf` up so "Core is capped at five" and "the test must be a real decision" stay visible. Nothing needs a screen, nothing needs an account.

## Print list

- Value deck: poker spec — print the deck sheet twice if you run it with a group.
- Poster: A3, one per room (optional but recommended).
- Run sheet: A4 (or Letter), one for the facilitator.
