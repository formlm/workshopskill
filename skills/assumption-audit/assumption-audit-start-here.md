# Assumption Audit — Start Here

> One page, thirty seconds, then print and run.

**What this is:** A 20-minute, 3–8 person pass that surfaces the unwritten things a plan needs to be true, tags each Evidence / To-verify / Fragile-if-false, and ranks the fragile ones down to the two or three that would actually break it — each with an owner and a date. Printable assumption cards, no account. 3–8 people · 20 min · offline + online.

## Pick your lane

- **Just run it (5 min):** put the plan up, silent-brainstorm the assumptions, tag, rank the fragile ones, assign who-checks-by-when. No projector, no account.
- **Before a real commitment:** run it on the plan you're about to approve — the point is to date the checks before the point of no return.
- **Remote:** the same silent-then-round-robin on a shared board; it transfers cleanly.

## Print list (per group)

An assumption-prompt card and the three tag cards within reach, plus blank cards so each assumption can be written and tagged. The `assumption-audit-activity-poster.pdf` goes on the wall so "who checks it, by when" stays visible. Nothing needs a projector or an account.
