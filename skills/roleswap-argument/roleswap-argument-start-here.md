# Roleswap Argument — Start Here

> One page, thirty seconds, then print and run.

**What this is:** A 20-minute, 6–16 person conflict reframe: take a real disagreement in the room, then make each side argue the *other* position honestly — steel-man it, land one true thing in it, and name the shared need underneath both. People leave able to state the opposing case without distortion. Printable cards, no account. 6–16 people · 20 min · offline + online.

## Pick your lane

- **Just run it (5 min):** state both positions, swap and argue the other side, steel-man it, each person names one true thing in it, name the shared need. No account, no projector.
- **Before a contested decision:** run the swap *first* — it's cheap insurance against a choice the other side won't support.
- **Too hot to run out loud:** drop into pairs with a neutral reader before any whole-group swap.

## Print list (per pair of sides)

One set of role cards per pair of sides, and one side of a wall (or shared board) per position with a spot left open for the shared need. The `roleswap-argument-activity-poster.pdf` goes on the wall so "argue to understand, not to win" and "land one true thing" stay visible. Nothing needs a projector or an account.
