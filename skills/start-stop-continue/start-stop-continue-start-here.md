# Start · Stop · Continue — Start Here

> One page, thirty seconds, then print and go.

**What this is:** The retrospective that fits on one wall: every card is one verb — start, stop, keep. No card survives without an owner and a date. Three-verb cards and a pre/post measure included. one team of 4–8 · 30 min.
