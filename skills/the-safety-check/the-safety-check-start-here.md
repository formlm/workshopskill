# The Safety Check — start here

One page, thirty seconds, then print and run.

**What this is:** a 20-minute, 4–12 person trust tool. Everyone privately rates four statements — I can ask a dumb question · I can admit a mistake · I can disagree with the decision-maker · I can take a risk without it being used against me — the team reveals the four bars together, circles the lowest one, and commits to a single behavior that would raise it, with a re-check date. No account, no projector. 4–12 people · 20 minutes · offline + online.

## Pick a route

- **Just run it (5 min):** private 1–5 dots on all four, reveal together, circle the lowest bar, name one behavior to raise it, set a re-check date.
- **New team, week one:** run it to say out loud what you want to be safe for — and that you're not there yet.
- **After something went wrong:** check the "admit a mistake" bar first; unreported problems start there.

## Set the room

A team that shares decisions, facing one board with the four statements up. Dots carry no names. Optional: put `the-safety-check-activity-poster.pdf` on the wall so "keep it anonymous" and "the lowest score is the target" stay visible. Nothing needs a projector, and nothing needs an account to download.

## Print checklist

- Statement + prompt cards: poker spec, one set per group.
- Poster: A3, one per room (optional, but it holds the two rules up).
- Run sheet: A4 (or Letter), one per facilitator.
