# The Leader Checkup — start here

> One page, thirty seconds, then print and run.

**WHAT THIS IS：** one leader and the people who report to them · 25 分钟 · Upward feedback, written before it is spoken: what is working, what quietly blocks the team, one ask. The leader listens without defending, then commits to one change.

## Print list, by scenario

- **In the room:** one the-leader-checkup-worksheet.pdf per group, one the-leader-checkup-prop-cards.pdf deck per table, the-leader-checkup-activity-poster.pdf on the wall (optional but it holds the rule up).
- **On the screen:** the-leader-checkup-slide-deck.html in any browser — S opens the presenter drawer, T starts the round timer; the-leader-checkup-slide-deck.pdf is the same deck for print.
- **For each participant:** the-leader-checkup-workbook.pdf — the sheet as fill-in pages, session notes and a before-you-leave page.
- **A4 and US Letter:** every print document ships in both; files ending in -Letter.pdf are the Letter editions.
