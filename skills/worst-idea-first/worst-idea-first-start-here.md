# Worst Idea First — Start Here

> One page, thirty seconds, then print and go.

**What this is:** Reverse brainstorming: spend five minutes engineering how the project fails, then flip every item into prevention. The awkward things get said inside a game that rewards saying them. 8–20 people (groups of 3–4) · 20 min.

## Pick your lane

| You are… | Open these | Print |
|---|---|---|
| Joining as a participant | the guide, then the workbook | `worst-idea-first-workbook.pdf` |
| Facilitating the session | the guide (minute-by-minute) + the deck | one answer sheet per person, the poker cards per table — first block before the session starts, second block right after the debrief |
| Handing it to your AI agent | `SKILL.md` | nothing yet — the agent runs the prep |
