# Step In If… — start here

One page, thirty seconds, then print and run.

**What this is:** a 15-minute, 8–20 person trust and belonging exercise. The group stands in a circle; statements are read aloud ("Step in if…"), and anyone they're true for steps into the centre, looks around at who's there, and steps back. No explanations, no names attached. 8–20 people · 15 minutes · offline + online.

## Pick a route

- **Just run it (5 min):** state the two rules, read 8–10 statements easiest-first, debrief what it felt like to step in, to stand alone, to see others there.
- **New team:** start with low-stakes statements and build toward the ones that matter.
- **After a hard project:** "step in if you were exhausted but kept going" — the shared load is the point.

## Set the room

A circle of standing people with a clear centre, safest statements first. Nobody explains a step; nobody audits who didn't take one. Optional: put `step-in-if-activity-poster.pdf` on the wall so "no one explains a step" and "you may only see who stepped in" stay visible. Nothing needs a projector, and nothing needs an account to download.

## Print checklist

- Statement & role cards: poker spec, one set per circle.
- Poster: A3, one per room (optional, but it holds the two rules up).
- Run sheet: A4 (or Letter), one per facilitator.
