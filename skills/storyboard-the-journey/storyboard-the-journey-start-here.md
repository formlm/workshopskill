# Storyboard the Journey — Start Here

> One page, thirty seconds, then print and run.

**What this is:** A 25-minute, 4–12 person mapping tool that lays one person's end-to-end experience out as a strip of storyboard panels, marks each with a high / low / hope, and draws the experience line through them — so the team argues about the same valley instead of their own box. Printable panel cards, no account. 4–12 people · 25 min · offline + online.

## Pick your lane

- **Just run it (5 min):** bind one journey, sketch the panels left-to-right, mark high/low/hope, draw the line, circle the dips. No projector, no account.
- **Before you prioritise a roadmap:** map the whole journey first so the fixes target the real valleys, not the loudest screen.
- **Remote:** the same strip on a shared board; it transfers cleanly.

## Print list (per group)

A journey-prompt card and a row of blank panels to draw on, plus the high/low/hope markers within reach. The `storyboard-the-journey-activity-poster.pdf` goes on the wall so "draw the line, don't list the steps" stays visible. Nothing needs a projector or an account.
