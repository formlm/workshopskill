## Print list, by scenario

- **In the room:** one the-delegation-map-worksheet.pdf per group, one the-delegation-map-prop-cards.pdf deck per table, the-delegation-map-activity-poster.pdf on the wall (optional but it holds the rule up).
- **On the screen:** the-delegation-map-slide-deck.html in any browser — S opens the presenter drawer, T starts the round timer; the-delegation-map-slide-deck.pdf is the same deck for print.
- **For each participant:** the-delegation-map-workbook.pdf — the sheet as fill-in pages, session notes and a before-you-leave page.
- **A4 and US Letter:** every print document ships in both; files ending in -Letter.pdf are the Letter editions.
