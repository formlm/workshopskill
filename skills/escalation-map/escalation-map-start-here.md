# Escalation Map — Start Here

> One page, thirty seconds, then print and run.

**What this is:** A 25-minute, 4–12 person conflict post-mortem that plots the arc of a getting-hot disagreement as a heat ladder — Warm · Heated · Boiling · Point of no return — writes what could have kept each rung one degree cooler, and circles the earliest cheap move. Names are not allowed on the map; only the shape of getting hot. Printable rung cards, no account. 4–12 people · 25 min · offline + online.

## Pick your lane

- **Just run it (5 min):** draw the four-rung ladder, sticky-note what happened at each level, write a cheap move per rung, circle the earliest one, each person names their next-time move.
- **Before the next tense moment:** run it on a conflict that just cooled — the map will name the rung you're actually sitting on right now.
- **Remote:** the same ladder on a shared board; it transfers cleanly.

## Print list (per group)

Four rung cards spread as a ladder on the wall, one "one degree cooler" card in reach, and blank cards for events and moves. The `escalation-map-activity-poster.pdf` goes up so the "no names, only shape" rule stays visible. Nothing needs a projector or an account.
