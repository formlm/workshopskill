# Mad · Sad · Glad — start here

One page, thirty seconds, then print and run.

**What this is:** a 20-minute, 6–20 person retrospective. Everyone writes what made them mad, sad, and glad about the last cycle, the team clusters and dot-votes the notes, and lands one concrete, owned action per colour. 6–20 people · 20 minutes · offline + online.

## Pick a route

- **Just run it (5 min):** silent notes into three columns, cluster, dot-vote, one action per colour, owners + revisit date.
- **First retro ever:** run it anonymous on a shared doc — people won't say hard things with their name on a Sad note.
- **A draining project:** give Sad and Glad equal airtime to Mad; morale needs acknowledging before problems get fixed.

## Set the room

One team that just finished a shared cycle, facing three labelled columns — Mad, Sad, Glad. Notes carry no names. Optional: put `mad-sad-glad-activity-poster.pdf` on the wall so "one item per note" and "one owned action per colour" stay visible. Nothing needs a projector, and nothing needs an account to download.

## Print checklist

- Column cards: poker spec, one set per team.
- Poster: A3, one per room (optional, but it holds the two rules up).
- Run sheet: A4 (or Letter), one per facilitator.
