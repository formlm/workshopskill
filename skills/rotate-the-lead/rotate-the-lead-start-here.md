# Rotate the Lead — start here

> One page, thirty seconds, then print and run.

**WHAT THIS IS：** one working group of 8–16 (two parallel rounds above 12) · 25 分钟 · One real task, four leads. Every handover restates goal, done-so-far and next before anyone directs; every lead makes one visible, owned call.

## What every file is

## Print list, by scenario

- **In the room:** one rotate-the-lead-worksheet.pdf per group, one rotate-the-lead-prop-cards.pdf deck per table, rotate-the-lead-activity-poster.pdf on the wall (optional but it holds the rule up).
- **On the screen:** rotate-the-lead-slide-deck.html in any browser — S opens the presenter drawer, T starts the round timer; rotate-the-lead-slide-deck.pdf is the same deck for print.
- **For each participant:** rotate-the-lead-workbook.pdf — the sheet as fill-in pages, session notes and a before-you-leave page.
- **A4 and US Letter:** every print document ships in both; files ending in -Letter.pdf are the Letter editions.
