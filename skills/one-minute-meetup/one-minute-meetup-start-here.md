# One-Minute Meetup — Start Here

> One page, thirty seconds, then print and run.

**What this is:** A 15-minute, 6–20 person energizer where pairs get exactly one minute to find a *surprising* shared thing, then rotate — three timed rounds plus a one-line gallery — so a room of semi-strangers learns real common ground faster than open mingling ever does. Printable cards, no account. 6–20 people · 15 min · offline + online.

## Pick your lane

- **Just run it (5 min):** hand out tally cards, pair off, run the three one-minute rounds and the gallery. You need a chime and a pen.
- **Run it remote:** same thing in breakout rooms, three rotations; you ring the chime on mute-all. The paper version works identically on a screen.
- **Make the asks yours:** the three round-asks live on the cards — swap them for your team's real ice (a project, a hobby, a hard-earned lesson).

## Print list (per person)

One tally card and a pen; one round-ask card for the room (or one set of three if you run the deeper asks). Run pairs around the room or across breakout rooms. The poster needs no print to run the energizer.
