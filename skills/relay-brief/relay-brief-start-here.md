# Relay Brief — Start Here

> One page, thirty seconds, then print and run.

**What this is:** A five-constraint task brief passed by whisper down a line of four to six people; the last person rebuilds it out loud. The distance between the original and the rebuild is the lesson about how verbal handover leaks — with cards to run the line and a pre/post measure on handover discipline. 8–20 people · 20 min · offline + online.

## Pick your lane

- **Just run it (5 min):** write one five-constraint brief on the brief card, line up 4–6 facing away, run the relay, reveal, debrief. No account, no projector.
- **Measure it:** run the pre-measure before lining up and the post-measure after the debrief — score the individual before/after delta and the team's average shift with `relay-brief-assessment.json` (5 items, two reverse-scored). Offline scoring needs no tool; `SKILL.md` carries a copy-paste method.
- **Go online (optional):** lift the same 5 items into a live pre/post form — see the folder's *make it live* block. The paper version is complete without it.

## Print list (per line of 4–6)

One brief card (facilitator only), one rebuild-record card for each of the last three hops, one observer tally card, one workbook and two answer sheets per person. Run two lines in parallel for a room over ~12. The deck needs no print — open the HTML on any laptop.
