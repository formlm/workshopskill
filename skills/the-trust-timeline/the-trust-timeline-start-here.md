# The Trust Timeline — start here

One page, thirty seconds, then print and run.

**What this is:** a 25-minute, 4–10 person trust tool. A team lays its shared history on a line — moments trust grew, broke, and got repaired — reads the pattern of what breaks and rebuilds trust here, and picks one live break to repair with an owner and a check-in date. No account, no projector. 4–10 people · 25 minutes · offline + online.

## Pick a route

- **Just run it (5 min):** draw the line and three lanes (Grew · Broke · Repaired), everyone posts real moments, read the pattern aloud, pick one live break and name a repair + owner + check-in date.
- **After a specific rupture:** put that break in the middle and map what would move it to the Repaired lane.
- **New team, no history yet:** run it forward — agree now how you'll mark growth and repair.

## Set the room

A horizontal line on the wall with three lanes — Grew · Broke · Repaired. Cards in hand. Stick `the-trust-timeline-activity-poster.pdf` up so "real moments, not ideals" and "no names on break cards" stay visible. Nothing needs a screen, nothing needs an account.

## Print list

- Cards: poker spec, one sheet per person (cut on the guides).
- Poster: A3, one per room (optional but recommended).
- Run sheet: A4 (or Letter), one for the facilitator.
